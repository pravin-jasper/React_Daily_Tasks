# React Todo List & Show/Hide Password

A beginner-friendly React application that demonstrates **useState, Events, Conditional Rendering, and Tailwind CSS** in a single project.

## 🚀 Features

### 1. Todo List
- Add new tasks.
- Delete tasks.
- Mark tasks as completed.
- Display total tasks.
- Display completed tasks.
- Add tasks by clicking the Add button or pressing Enter.
- Show a message when the task list is empty.

### 2. Show/Hide Password
- Enter a password.
- Show the password by clicking the Show button.
- Hide the password by clicking the Hide button.
- Dynamically change the input type using conditional rendering.

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6)
- Tailwind CSS
- React useState Hook
- JSX



## ⚙️ Installation and Setup


### 1. Install dependencies

```bash
npm install
```

### 2. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.

## 📚 React Concepts Practiced

| Concept | Usage |
|---|---|
| useState | Manage todos and password visibility |
| onClick | Add, delete, complete tasks, show/hide password |
| onChange | Handle input changes |
| onKeyDown | Add tasks using Enter |
| Conditional Rendering | Display messages and toggle password visibility |
| map() | Display todo items |
| filter() | Delete tasks and count completed tasks |
| Ternary Operator | Toggle password input type and button text |

## 💡 Learning Objectives

- Understand React state management.
- Handle user events in React.
- Update arrays using state.
- Implement conditional rendering.
- Build responsive interfaces using Tailwind CSS.
