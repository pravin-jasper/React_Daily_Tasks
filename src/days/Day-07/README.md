# React Router Multi-Page App 🚀

A responsive Multi-Page React Application built using React.js, React Router DOM, JavaScript, and Tailwind CSS. This project demonstrates client-side routing, navigation, reusable components, and page rendering without refreshing the browser.

## 🚀 Features

- Create a multi-page React application.
- Navigate between three pages.
- Home page.
- About page.
- Contact page.
- Navigate between pages without refreshing the browser.
- Highlight the active navigation link.
- Reusable Navbar component.
- Responsive navigation menu.
- Modern UI using Tailwind CSS.
- Responsive design for mobile and desktop devices.

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- React Router DOM
- Tailwind CSS
- HTML5
- JSX



## 📚 React Concepts Practiced

| Concept             | Usage                                               |
| ------------------- | --------------------------------------------------- |
| `BrowserRouter`     | Enable routing in the React application             |
| `Routes`            | Group all route definitions                         |
| `Route`             | Connect URLs with page components                   |
| `NavLink`           | Navigate between pages and highlight active links   |
| `element`           | Render the corresponding page component             |
| Components          | Create reusable Navbar and page components          |
| Props               | Pass styling and component information where needed |
| Conditional Styling | Apply different styles to active navigation links   |
| Tailwind CSS        | Style the application and create responsive layouts |

## 🌐 Routing

This project uses React Router DOM for client-side navigation.

### 1. Home Page

URL:

```text
/
```

Displays the home page content.

### 2. About Page

URL:

```text
/about
```

Displays information about the website.

### 3. Contact Page

URL:

```text
/contact
```

Displays contact information.

## ⚙️ Installation and Setup

### 1. Navigate to the project folder

```bash
cd day7
```

### 2. Install dependencies

```bash
npm install
```

### 3. Install React Router DOM

```bash
npm install react-router-dom
```

### 4. Install Tailwind CSS

For Tailwind CSS v4 with Vite:

```bash
npm install tailwindcss @tailwindcss/vite
```

### 5. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.
